🔑 3. KONEKSI DATABASE
ENV yang dipakai:
MYSQL_URL=root:pon@tcp(localhost:3306)/cobagolang
File: config/db.go
dsn := os.Getenv("MYSQL_URL")
db, _ := sql.Open("mysql", dsn)
db.Ping()
❗ Problem yang sempat terjadi:
DSN kosong → ❌ No database selected
SOLUSI: set ENV di PowerShell
$env:MYSQL_URL="root:pon@tcp(localhost:3306)/cobagolang"
🔐 4. LOGIN SYSTEM
Flow:
user input di HTML
kirim via fetch (JSON)
backend decode JSON
cek DB
generate JWT
simpan di localStorage
❗ Bug yang terjadi:
❌ username kosong

Penyebab:

backend pakai FormValue
frontend kirim JSON
✅ solusi:
json.NewDecoder(r.Body).Decode(&user)
🔑 5. JWT AUTH
Setelah login:
localStorage.setItem('token', data.token)
Dipakai di request:
headers: {
  Authorization: 'Bearer ' + token
}
Middleware:
func AuthMiddleware(next http.HandlerFunc) http.HandlerFunc {
  return func(w http.ResponseWriter, r *http.Request) {
    tokenStr := r.Header.Get("Authorization")
    // validasi JWT
  }
}
📦 6. CRUD ITEMS
Endpoint:
Method	Endpoint
GET	/items
POST	/items/create
Frontend:
Load data:
const res = await fetch('/items', {
  headers: { Authorization: 'Bearer ' + token }
})
Tambah item:
await fetch('/items/create', {
  method: 'POST',
  headers: { Authorization: 'Bearer ' + token },
  body: JSON.stringify({ name: inputName.value })
})
❗ BUG YANG KITA FIX
1. ❌ name.value undefined

👉 penyebab:

name.value

👉 solusi:

document.getElementById('name')
2. ❌ data kosong

👉 solusi:

if (data.length === 0) {
  list.innerHTML = "Belum ada data"
}
3. ❌ password selalu salah

👉 penyebab:

bcrypt vs plain text
JSON vs form mismatch

👉 solusi:

samakan format
sementara pakai plain
4. ❌ No database selected

👉 penyebab:

ENV tidak terbaca

👉 solusi:

set MYSQL_URL
